# dokuwiki-tagentry

DokuWiki plugin to assign page tags by clicking checkboxes in edit mode.

Requires the [Tag Plugin](https://www.dokuwiki.org/plugin:tag).

See: https://www.dokuwiki.org/plugin:tagentry

## Compatibility

This version has been updated for DokuWiki 2025-05-14a "Librarian" (PHP 8.3.30).
